# Price Sense – SQL Driving Pricing Intelligence

## Overview

Price Sense is a real-world SQL analytics project completed as part of the **Summer Project 2026** organized by **E-Cell IIT Guwahati** in collaboration with **AI Palette**.

The objective of this project was to analyze pricing data, consumer behavior, product metadata, competitor pricing, and geographical information to derive actionable business insights using SQL.

---

## Project Objectives

- Clean and preprocess raw datasets
- Analyze customer purchasing behavior
- Build a pricing sensitivity framework
- Optimize pricing using contextual information
- Generate business insights using SQL

## Datasets

The project uses five datasets:

| Dataset | Description |
|---------|-------------|
| product_metadata.csv | Product category, claims, ingredients and pack size |
| transactions.csv | Customer transactions including price, quantity and sales channel |
| consumer_insights.csv | Customer personas, demographics and preferences |
| competitor_pricing.csv | Competitor pricing history over time |
| geography_occasion.csv | State, city tier and purchase occasion information |

---

## SQL Workflow

Execute the SQL scripts in the following order:

1. Data_Cleaning.sql
2. Sensitivity_Framework.sql
